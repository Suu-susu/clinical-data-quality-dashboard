Clinical Data Quality Dashboard

A self-directed data science portfolio project by Jiashuo Su using synthetic patient-monitoring data. The dashboard demonstrates cleaning logic, quality checks, visual analysis, risk flagging, and stakeholder-facing insights.

Case study

Python-style pipeline Data quality Clinical monitoring Dashboard Synthetic data

Problem

Clinical sensor data can contain missing values, sudden spikes, duplicate timestamps, or signal drift. Before results are used for insight generation, analysts need a repeatable way to check whether the data is complete, consistent, and clinically interpretable.

Approach

1Load synthetic patient-monitoring records with pressure, signal quality, battery level, and review status.
2Apply validation checks for missing readings, outliers, low signal quality, duplicate timestamps, and review flags.
3Visualise trends and quality issues so technical and non-technical stakeholders can understand the result.
4Produce recommendations for follow-up review, pipeline improvement, and clinical data quality monitoring.

What this shows

  • Ability to structure an analytical workflow around data quality, not just charts.
  • Practical dashboard communication for clinical, product, and engineering audiences.
  • Readiness to support pipeline optimisation, visualisation, and insight generation.

Honest positioning

This is not real patient data and not commercial work. The dataset is synthetic and used only to demonstrate clinical data science thinking for an internship application.
